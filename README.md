# AION Video Editor

AION은 전문가와 초보자 모두 쉽게 사용할 수 있는 오픈소스(MIT) 비디오 편집기입니다.
기존 프로그램(Edius 등)과 유사한 타임라인 편집 경험, 자동 자막(Auto-Captions), 그리고 빠르고 쾌적한 렌더링 성능을 제공합니다.

## 🚀 다운로드 및 설치 방법 (한국어 사용자 가이드)

AION은 설치 과정이 매우 간단합니다!

> **[안내] 현재 클라우드 렌더링 서버(빌드 시스템) 안정화 작업 중입니다.** 
> 조만간 아래 링크를 통해 정식 .exe 설치 파일이 배포될 예정입니다.컴파일러를 원작자님이 안해놓으셔서 굉장히 까다로운작업이 될것같습니다 pc사양이 좋으신분들은 클론해가세요

1. 우측의 **[Releases]** 메뉴를 클릭하거나 [여기](https://github.com/psb684-sketch/AION/releases)를 누르세요.
2. 가장 최신 버전에서 **AION_x64_setup.exe** (또는 .msi) 파일을 다운로드합니다.
3. 다운로드받은 파일을 더블클릭하여 설치를 진행합니다.
4. 바탕화면에 생성된 **AION** 아이콘을 눌러 편집을 시작하세요!

## ✨ 주요 기능

*   **한국어 완벽 지원**: 어려운 방송 편집 용어를 직관적인 한국어로 번역했습니다 (타임라인, 잔물결 모드, 시작점 다듬기 등).
*   **오프라인 자동 자막**: 인터넷 연결 없이도 작동하는 AI(Whisper) 기반 자동 자막 생성을 지원합니다.
*   **초고속 렌더링 & 부드러운 미리보기**: 최신 WebGPU 기술을 사용하여 4K 영상도 끊김 없이 편집할 수 있습니다.
*   **다양한 트랜지션 및 효과**: 필수적인 비디오 효과 및 화면 전환 기능을 제공합니다.
