# AION Video Editor

AION은 직관적이고 빠른 컷 편집을 위해 제작된 오픈소스(MIT) 기반 비디오 편집기입니다.
무거운 프로그램 없이도 전문가급 타임라인 컷 편집, 자동 자막(Auto-Captions), 비디오 트랜지션 기능을 무료로 사용할 수 있습니다.

## 🚀 다운로드 및 설치 방법 (한국어 사용자 가이드)

AION은 설치 과정이 매우 간단합니다!

1. 우측의 **[Releases]** 메뉴를 클릭하거나 [여기](https://github.com/USER_NAME/AION/releases/latest)를 누르세요.
2. 가장 최신 버전에서 **AION_x64_setup.exe** (또는 .msi) 파일을 다운로드합니다.
3. 다운로드받은 파일을 더블클릭하여 설치를 진행합니다.
4. 바탕화면에 생성된 **AION** 아이콘을 눌러 편집을 시작하세요!

## ✨ 주요 기능

*   **한국어 완벽 지원**: 편집 용어를 직관적인 한글로 구성했습니다 (타임라인, 잔물결 편집, 자르기 등).
*   **오프라인 자동 자막**: 인터넷 연결 없이도 동작하는 AI(Whisper) 기반 자동 자막 생성 기능을 지원합니다.
*   **자석 스냅 & 빈 공간 삭제**: 에디우스(Edius) 스타일의 빠르고 직관적인 타임라인 편집 경험을 제공합니다.
*   **다양한 트랜지션 및 효과**: 필수적인 비디오 효과와 장면 전환 기능을 무료로 제공합니다.
